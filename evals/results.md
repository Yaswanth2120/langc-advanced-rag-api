# DocuIntelAI RAG Evaluation Results

Backend: **local_hash embeddings**, **none (extractive fallback)** generation. Generated by `evals/run_eval.py`.

Local hashing-embedding retrieval (deterministic bag-of-words cosine similarity over Chroma, no LLM) plus an extractive answer — a fast, reproducible smoke test of the retrieval plumbing, not a measure of production answer quality. Run `make eval-live` with `OPENAI_API_KEY` set for a real accuracy measurement against OpenAI embeddings + chat generation.

The corpus includes near-miss distractors (two space-exploration docs),
an adjacent-topic negative case, and a paraphrase case with no lexical
overlap with its source chunk — see `evals/questions.json` for notes on
what each is designed to catch.
